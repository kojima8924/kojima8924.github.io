## 自動検査の再実行

リポジトリルートから実行します．

```powershell
python scripts/check_portfolio.py
python scripts/check_portfolio.py --external
python -m unittest discover -s tests -v
python scripts/import_figures.py --check
```

`import_figures.py --check`はPyMuPDFで参照元PDFからSVGをメモリ内に生成し，改行を正規化した既存SVGと内容を比較します．参照元PDFまたは出力SVGの欠損，生成内容との差異があれば終了コード1を返します．mtimeは判定に使いません．

通常変換でも対象PDFを事前にすべて検証し，欠損があれば何も変換しません．SVGは出力先と同じディレクトリの一時ファイルへ書き終えてから置換し，書き込み失敗時は既存SVGを保持します．
