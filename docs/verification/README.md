後者はPyMuPDFを使って参照元PDFからSVGをメモリ内で生成し、改行を正規化した既存SVGと内容を比較する。
参照元PDFの欠損、出力SVGの欠損、または生成内容との差異がある場合に終了コード1を返す。
mtimeは判定に使わないため、同一内容のPDFを再生成しただけでは更新要にならない。
通常変換でも対象PDFを事前にすべて検証し、1件でも欠損していれば何も変換せず終了コード1を返す。
SVGは出力先と同じディレクトリの一時ファイルへ書き終えてから置換し、書き込み失敗時は既存SVGを保持する。
